# MarketFlow frontend

React 19 and Vite frontend for the MarketFlow retail operations system.

## Run locally

```powershell
npm install
npm run dev
```

The dashboard API base URL defaults to `http://localhost:5192/api`. Override it by setting `VITE_API_BASE_URL` before starting Vite.

## Available scripts

- `npm run dev` — start the Vite development server.
- `npm run build` — create a production build.
- `npm run lint` — run Oxlint.
- `npm run preview` — preview the production build.
